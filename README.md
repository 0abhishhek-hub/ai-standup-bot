# AI Daily Standup & Work Logger Bot ☕
Autonomous standup generator powered by Groq LLaMA-3.3 / Google Gemini running 24/7 on a headless Linux server.

## Features
- Extracts recent 24-hour git commits across repositories
- Generates executive-ready Slack/Teams standup summaries
- Direct Telegram notifications

## Usage
```bash
python3 standup.py [optional_path_to_git_repo]
